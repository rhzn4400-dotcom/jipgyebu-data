개인정보처리방침

집계부 · 시행일 2026년 9월 28일

「집계부」(이하 '앱')는 이용자의 개인정보를 수집하지 않도록 설계되었습니다. 이 방침은 앱이 어떤 정보를 어디에 저장하고, 무엇을 외부와 주고받는지 설명합니다.

1. 수집하는 개인정보

앱은 이름·전화번호·이메일·위치·기기 식별자 등 개인정보를 수집하지 않으며, 회원가입과 로그인이 없습니다. 앱 운영자는 이용자가 누구인지, 어느 단지를 선택했는지 알 수 없습니다.

2. 기기에만 저장되는 정보

이용자가 직접 입력·선택한 아래 정보는 이용자의 기기 안에만 저장되며 외부로 전송되지 않습니다.

  • 선택한 우리 단지, 입력한 전용면적
  • 관심 단지 목록
  • 비교 기간·비교군 조건·알림 켜기 여부 등 설정
  • 홈 화면 위젯에 표시할 요약 문구

이 정보는 앱을 삭제하거나 휴대폰 설정에서 앱 데이터를 삭제하면 함께 지워집니다.

3. 외부와 주고받는 정보

앱의 외부 통신은 국토교통부 공동주택관리정보시스템(K-apt) 공개자료로 만든 관리비 데이터 파일을 내려받는 것 하나뿐입니다. 이 요청에는 이용자가 선택한 단지나 입력값이 포함되지 않으며, 모든 비교 계산은 기기 안에서 이루어집니다. 다만 인터넷 통신의 특성상 파일을 제공하는 호스팅 서비스에 접속 IP 주소 등 일반적인 접속 기록이 남을 수 있으며, 앱 운영자는 이를 이용자 식별에 사용하지 않습니다.

4. 앱이 사용하는 권한

  • 인터넷: 관리비 데이터 파일을 내려받기 위해 사용합니다.
  • 알림(선택): 이용자가 '새 관리비 공개 알림'을 켠 경우에만 요청하며, 새 달 관리비가 공개되면 한 번 알려드립니다. 설정에서 언제든 끌 수 있습니다.

위치·연락처·사진·저장공간 권한은 사용하지 않습니다.

5. 공유 기능

'요약 이미지 공유'를 누르면 이미지가 기기 안에서 만들어지고, 이용자가 직접 고른 앱(메신저·메일 등)으로 전달됩니다. 앱이 이미지를 따로 업로드하거나 보관하지 않습니다.

6. 광고·결제·분석

현재 앱에는 광고, 이용 행태 분석, 결제 기능이 없습니다. 앞으로 광고나 유료 기능을 도입하면 그에 따라 처리되는 정보(예: 광고 식별자, 구매 내역)와 처리하는 곳을 이 방침에 먼저 반영하고 앱 안에서 알려드립니다.

7. 제3자 제공 및 처리 위탁

앱은 개인정보를 수집하지 않으므로 제3자에게 제공하거나 처리를 위탁하는 개인정보가 없습니다.

8. 아동의 개인정보

앱은 만 14세 미만 아동을 포함해 누구의 개인정보도 수집하지 않습니다.
